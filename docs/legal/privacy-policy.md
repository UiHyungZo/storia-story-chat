# Storia 개인정보처리방침

시행일: 2026-08-26

Storia("본 앱")는 AI 캐릭터와 텍스트/음성으로 대화하는 개인 포트폴리오 프로젝트입니다. 본 방침은 본 앱이 수집하는 정보와 그 처리 방식을 설명합니다.

## 1. 회원가입 없는 익명 서비스

본 앱은 이메일/전화번호 기반 회원가입이나 로그인을 요구하지 않습니다. 앱을 처음 실행하면 기기 내에 무작위 식별자(UUID, "디바이스 ID")가 하나 생성되어 서버와의 통신에 사용됩니다. 이 식별자는 실명, 이메일, 전화번호 등 개인을 특정할 수 있는 정보와 연결되어 있지 않습니다. 앱을 삭제하거나 재설치하면 새 식별자가 발급되며, 이전 대화 기록과의 연결은 끊어집니다.

## 2. 수집하는 정보

| 항목 | 설명 |
|---|---|
| 디바이스 ID | 위 1항의 무작위 UUID. 대화 기록을 특정 세션에 연결하는 용도로만 사용됩니다. |
| 대화 메시지 내용 | 사용자가 AI 캐릭터에게 보낸 텍스트와 캐릭터의 응답. 대화 이어가기(히스토리 복원)를 위해 서버에 저장됩니다. |
| 음성 통화 오디오 | 음성 통화 기능 사용 시 마이크 오디오가 실시간으로 서버에 전달되어 텍스트 변환(STT) 및 응답 생성에 사용됩니다. 오디오 파일 자체는 별도로 저장되지 않고, 처리 직후 폐기됩니다. |
| 푸시 알림 토큰 | 알림 수신에 동의한 경우 발급되는 FCM(Firebase Cloud Messaging) 토큰. 새 메시지/재참여 알림 발송 목적으로만 사용됩니다. |
| 마지막 활동 시각 | 재참여 알림 발송 시점을 판단하기 위해 저장됩니다. |
| 진단/충돌 정보 | 앱 충돌이나 오류 발생 시 자동으로 수집되는 스택 트레이스, 기기/OS 버전 등 기술 정보(Sentry). 개인 식별 정보는 포함하지 않습니다. |

본 앱은 위치 정보, 연락처, 사진첩 등에는 접근하지 않습니다.

## 3. 정보 이용 목적

- AI 캐릭터와의 대화 생성 및 이어가기(히스토리 복원)
- 음성 통화 기능 제공(음성 인식 → 대화 생성 → 음성 합성)
- 새 메시지/재참여 푸시 알림 발송
- 앱 오류 진단 및 안정성 개선

## 4. 제3자 제공 및 위탁

본 앱은 아래 서비스를 이용해 기능을 제공하며, 각 서비스는 해당 목적 범위 내에서만 필요한 데이터를 처리합니다.

- **Google Gemini API** — 사용자 메시지를 전달받아 AI 응답을 생성합니다.
- **Google Cloud Speech-to-Text / Text-to-Speech** — 음성 통화 시 음성↔텍스트 변환을 처리합니다.
- **LiveKit** — 음성 통화의 실시간 오디오 전송(WebRTC 중계)을 처리합니다.
- **Firebase Cloud Messaging (Google)** — 푸시 알림 발송을 처리합니다.
- **Sentry** — 앱 충돌/오류 진단 정보를 수집합니다.

각 서비스는 자체 개인정보처리방침에 따라 운영되며, 본 앱은 서비스 제공에 필요한 최소한의 데이터만 전달합니다. 이 외의 목적으로 개인정보를 판매하거나 제3자에게 제공하지 않습니다.

## 5. 보관 기간

대화 메시지와 디바이스 ID는 사용자가 앱을 계속 사용하는 동안 보관됩니다. 삭제를 원하시면 아래 문의처로 디바이스 ID(설정 화면 또는 앱 재설치 전 확인 가능) 또는 삭제 요청 사유를 알려주시면 해당 데이터를 삭제해 드립니다.

## 6. 아동의 개인정보

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동으로부터 고의로 개인정보를 수집하지 않습니다.

## 7. 개인정보 보호를 위한 노력

본 앱은 합리적인 수준의 기술적 조치를 통해 데이터를 보호합니다. 다만 본 앱은 상용 서비스가 아닌 포트폴리오 프로젝트로, 상시 운영되는 프로덕션 인프라를 전제로 하지 않는다는 점을 참고해 주시기 바랍니다.

## 8. 방침 변경
